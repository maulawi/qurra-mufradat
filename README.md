# QURRA Mufradat al-Qur'an (مفردات القرآن)

A vocabulary explorer for the words of the Qur'an, organised Juz → Surah → Ayah → Word, in English and
Bahasa Melayu. The complete Qur'anic text is included. Word-by-word analysis (segmentation, lemma, root, meaning) is
provisional and covers about four fifths of the words; the rest are shown as text only. Part of the QURRA product family (alongside
QURRA Grammar).

**This is NOT:** a grammar parser, an i'rab/case-analysis tool, a tafsir app, a flashcard/quiz app, or a
complete morphological database. See ROADMAP.md for what those would be.

## Current state

| | |
|---|---|
| Qur'anic text | **Complete**: 114 surahs, 6,236 ayahs, from the official Tanzil text (Uthmani, v1.1), displayed verbatim |
| Text-derived tokens | **77,441** (one per written word); every word of the Qur'an is browsable and searchable |
| Word analysis (segmentation, lemma, root, meaning EN + BM, morphology) | **About four fifths of the words** (`docs/V1_COVERAGE_REPORT.md` has exact figures): a **provisional** QURRA-written analysis, generated by rules from a hand-written lexicon (`docs/word-analysis-method.md`). The pilot's 91 tokens keep their own analysis. |
| Words without analysis | Shown with their text only and labelled "not yet analysed". Nothing is guessed. |
| Roots | **Provisional** where the dictionary root is not in doubt; disputed or unresolved roots are not shown and not indexed. None is reviewed or verified. |
| Root protocol | **Not frozen**: pending expert review (`docs/expert-review/`, not sent to anyone) |
| External morphology datasets | **None imported**: none has a cleared licence (`docs/content-source-research.md`) |

Token coverage is complete; morphological coverage is not. See **STAGE_3_REPORT.md** for the details of the
latest stage, **STAGE_2_IMPLEMENTATION.md** for the data model, validation and provenance, and
**NOTICE** for third-party attribution (Tanzil).

## Stages so far

- **Stage 3**: complete official Tanzil text and metadata, deterministic token layer, full-text search.
- **Stage 2**: validated, provenance-carrying data pipeline (`data/` → `node scripts/build.js` → `js/generated/`),
  source registry, taxonomy, status/display policy.
- **Stage 1 / 1.5 (v0.2)**: static prototype and browser-QA fixes. Fully bilingual UI (English default,
  Bahasa Melayu) via the "EN | BM" switcher; the choice persists (`localStorage`). Qur'anic text and Arabic
  grammatical terminology are never translated. See **ARCHITECTURE.md §11** for the i18n architecture.

## How to run locally

No install step is required to *run* it: this is plain HTML/CSS/JavaScript with no runtime dependencies.
To change the data, edit `data/*.json` and run `node scripts/build.js` (Node 18+, no npm packages) to
validate, test and regenerate `js/generated/*`. `npm run check` fails if the generated files are stale.

**Option A: VS Code Live Server (recommended):** right-click `index.html` → "Open with Live Server".

**Option B: any static file server:**
```
python3 -m http.server 8000
# then open http://localhost:8000 in a browser
```

**Option C: open `index.html` directly.** Works for a quick look, though a local server is recommended
(some browsers restrict font loading from `file://`).

## How to deploy to GitHub Pages

1. Push this repository to GitHub.
2. In the repo's **Settings → Pages**, set the source to the branch and root folder containing `index.html`.
3. No build step is needed: `js/generated/*` is committed. The app uses hash-based routing
   (`#/surah/2/ayah/255`), so every route works as a direct link and survives a refresh.

## Architecture overview

Vanilla JS, no framework, no bundler. Each `js/*.js` file defines one global module, loaded via classic
`<script>` tags in dependency order. Screens are rendered as HTML strings from data (via `QMData`);
navigation is native hash-link navigation. The data is compiled from `data/` into two static JS files, so
there is no backend, database, authentication or API. Full detail in **ARCHITECTURE.md** and
**STAGE_2_IMPLEMENTATION.md**.

## What's functional

- Home with a 30-card Juz grid (Juz with pilot word analysis are marked; all Juz have text)
- Juz → Surah → Ayah navigation for all 114 surahs; Surahs, Roots and Lemmas indexes
- Clickable Qur'anic word → progressive-disclosure detail panel. For analysed words: segmentation, part of
  speech, lemma, gloss, morphology, root (provisional, labelled), sources. For all other words: the text,
  its location and an explicit "word analysis not available yet" note
- Search across the whole Qur'anic text (normalised Arabic, phrases, ayah references like `2:255`, surah
  names) and across lemma forms, glosses (EN/BM) and the provisional roots
- All/اسم/فعل/حرف filter (only for words that have an analysis)
- Full hash routing, responsive layout (checked at 360 / 390 / 768 / 1440 px), RTL Arabic with an LTR UI
- Bilingual UI (English, Bahasa Melayu), keyboard accessibility, focus states, `prefers-reduced-motion`

## Not implemented / known limitations

- No lemma, root or morphology for 77,398 of 77,441 tokens: no cleared full-Qur'an source exists yet
  (MASAQ and QuranMorph licences unresolved; QAC and Wikidata not used)
- The 9-ayah analysis is hand-written, provisional and not scholar-reviewed; the 23 roots are placeholders
- Pause marks and sajdah signs are not included in the displayed text (a Tanzil-supported option)
- Not yet translated per ayah beyond the 9 pilot working renderings, which are not authoritative
- No i'rab, no backend, database, login, flashcards, quizzes, tafsir or deep lexicon
- Only English and Bahasa Melayu UI languages
